# SpaceX Falcon 9 First-Stage Landing Prediction — IBM Applied Data Science Capstone

Predicts whether a Falcon 9 first stage will land successfully, to estimate launch cost.

| File | Contents |
|---|---|
| SpaceX_Capstone.ipynb | Full executed notebook: data collection, wrangling, EDA, SQL, maps, dashboard, ML |
| analyze.py | Data wrangling, EDA charts, SQL queries, model training (LogReg, SVM, Tree, KNN) |
| queries.sql | All SQL queries used for EDA |
| dashboard.py | Plotly Dash app (site dropdown, success pie chart, payload slider, scatter) |
| results.json | Recorded results |
| figures/ | Charts, maps and dashboard screenshots |
| Data_Science_Capstone_Project_Report.pdf | Final presentation |

Best CV model: SVM (88.9%). Best test accuracy: Decision Tree / KNN (83.3%).
